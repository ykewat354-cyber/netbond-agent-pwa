# NetBond Agent PWA

AI-powered OTT plan automation for netBond.in sellers.

## Install

1. Open this app in Chrome on your Android phone
2. Tap Menu (⋮) → "Install App" or "Add to Home Screen"
3. App icon appears on home screen!

## Features

- 🔐 Login to netBond.in
- 🎛️ Filter plans (Platform, Device, Price)
- 🤖 AI Analysis with Claude
- 📋 Copy/Save reports

## Usage

1. Login with netBond.in credentials
2. Set filters (optional)
3. Tap "Start Listing"
4. Tap "Analyze with AI" for insights
